# Admin and mobile integration checklist

- [ ] Restrict private playlist and track reads to their owners.
- [ ] Allow admins to publish playlists with playable tracks and discovery metadata.
- [ ] Make broadcast delivery and audience controls match mobile behavior.
- [ ] Synchronize admin deletions with mobile caches and schedules safely.
- [ ] Clarify or connect the admin's surah and mood catalogs to the mobile app.
- [ ] Replace misleading analytics placeholders with available data or clear unavailable states.
- [ ] Assess legacy Appwrite migration access and document remaining blockers.
- [ ] Run relevant automated checks and document deployment status.
