# Ambient background sounds — sources & license

Mono 44.1 kHz / 64 kbps MP3 loops, loudness-normalized (EBU R128-ish, I=-18),
capped at 75 s. Played looped under Quran recitation via a dedicated player
(`AmbientPlayerBridge`) with `REPEAT_MODE_ALL` / AVPlayer end-observer loop.
